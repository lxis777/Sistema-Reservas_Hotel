# Diagramas en formato UML (PlantUML)

- `diagrama_actores.puml`: casos de uso.
- `diagrama_er.puml`: entidad-relación.

Para verlos o exportarlos a PNG/SVG:
- En línea: pegar el contenido en https://www.plantuml.com/plantuml
- VS Code: extensión "PlantUML" (jebbs.plantuml) → Alt+D para previsualizar.
- IntelliJ / PyCharm: plugin "PlantUML Integration".
